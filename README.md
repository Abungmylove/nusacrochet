# Nusa Crochet & Crafts — 3D Product Landing Page

Landing page interaktif modern untuk brand **Nusa Crochet & Crafts**, dibuat dengan performa ultra-ringan menggunakan **Vite + React.js + Tailwind CSS**.

> **"Export quality, eco friendly materials, and empowering women with crochets & crafts talents from various areas."**

---

## 🌟 Fitur Utama
- **3D Parallax Tilt Effect**: Tas rajut melayang secara dinamis mengikuti arah kursor mouse (*zero friction motion* terinspirasi dari referensi Pinterest).
- **Interactive Color Switcher**: Transisi warna tas (*Lilac Dusk*, *Sage Meadow*, *Warm Terracotta*), lighting radial glow, dan background gradient dinamis.
- **Dynamic Size & Dimension Slider**: Pilihan ukuran (S, M, L) dengan kalkulasi otomatis dimensi, kapasitas muatan, dan harga.
- **Women Empowerment Section**: Mendedikasikan ruang khusus untuk narasi pemberdayaan perajin perempuan dari berbagai daerah nusantara.
- **Export & Eco Quality Pillars**: Menampilkan standar mutu ekspor dan material benang katun ramah lingkungan.
- **Direct WhatsApp Checkout Modal**: Formulir pemesanan instan yang otomatis merangkum data produk terpilih ke format pesan WhatsApp siap kirim.
- **Ultra Lightweight & Fast**: Ukuran bundle produksi hanya ~80 kB (gzipped) dengan *zero unnecessary bloat*.

---

## 🛠️ Tech Stack
- **Framework:** React.js 19
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS 3
- **Icons:** Lucide React
- **Typography:** Plus Jakarta Sans & Syne (Google Fonts)

---

## 🚀 Cara Menjalankan Proyek

### 1. Mode Development (Live Reload)
```bash
npm run dev
```
Akses di browser: `http://localhost:3000`

### 2. Build Produksi (Ringan & Cepat)
```bash
npm run build
```

### 3. Preview Hasil Build
```bash
npm run preview
```
Akses di browser: `http://localhost:4173`
